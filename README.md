## Laporan Praktikum: CRUD Laravel + Filament SMP Mentari

Aplikasi web management sekolah untuk **SMP Mentari** yang dibangun menggunakan:
- **Laravel 11.x** - PHP Framework
- **Filament v4** - Admin Panel
- **MySQL** - Database
- **MAMP** - Local Development Server (macOS)
